# Project Verification Record

Discover these values for the current addon before claiming completion:

- Addon project path and `*.gproj` file name and title.
- Workbench version and game version.
- Script compilation view and clean-result evidence.
- Resource editors required by changed file types.
- In-editor world, mission, or scenario used for behavior checks.
- Diagnostic tools or logs used and their output locations.
- Local or hosted multiplayer launch procedure.
- Authority/proxy roles and expected observations.
- Reload or restart requirements.

This file is synced from the template and holds no machine-specific values. Record the concrete answers in `.claude/local/workbench.md` (template: `local-workbench-template.md`), and only after they have worked for the addon.
