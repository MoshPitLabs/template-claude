# specs/

Project specs live here — PRDs, ADRs (`adr/`), TDDs (`tdd/`), UX specs (`ux/`),
and the reserved reference files (`security.md`, `architecture.md`, `testing.md`,
`code-quality.md`) generated by the `init-specs` skill. The `prd`/`adr`/`tdd`/`ux-spec`
skills write here and attach the file to the relevant td issue via `td link <id> specs/<file>`.
